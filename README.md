## 📦 خطوات تحويل التطبيق إلى APK (بالتفصيل)

### المرحلة 1: تجهيز الحسابات (مرة واحدة فقط)

#### 1. حساب GitHub
1. ادخل على: https://github.com
2. اضغط **Sign up** وسجل بحساب جديد (أو سجل دخول لو عندك حساب)
3. احفظ اسم المستخدم والباسورد

#### 2. لا تحتاج تحمل أي برنامج معقد
- الطريقة دي سهلة جداً وما تحتاج Android Studio

---

### المرحلة 2: رفع المشروع على GitHub

1. حمل مجلد المشروع `notes-app` كامل على جهازك
2. ادخل على GitHub وسجل دخول
3. اضغط على علامة **+** فوق يمين → **New repository**
4. اكتب اسم المستودع مثلاً: `mothakrati`
5. خليه **Public**
6. **لا تضغط** على Initialize this repository
7. اضغط **Create repository**

#### طريقة الرفع السهلة (من الموقع مباشرة):

1. بعد ما تعمل المستودع، هتلاقي صفحة فاضية
2. اضغط على **"uploading an existing file"**
3. اسحب كل ملفات مجلد `notes-app` (index.html + style.css + app.js + manifest.json + sw.js + مجلد icons + README.md)
4. اكتب في خانة الـ Commit: `أول رفع للتطبيق`
5. اضغط **Commit changes**

---

### المرحلة 3: تفعيل GitHub Pages (عشان التطبيق يبقى أونلاين)

1. داخل المستودع اضغط على تبويب **Settings**
2. من القائمة اليسار انزل لـ **Pages**
3. تحت **Source** اختار:
   - Branch: `main`
   - Folder: `/ (root)`
4. اضغط **Save**
5. استنى دقيقة أو اتنين
6. هتلاقي رابط زي كده:
   `https://YOUR_USERNAME.github.io/mothakrati/`

**انسخ الرابط ده واحفظه** — هتحتاجوه في الخطوة الجاية.

---

### المرحلة 4: تحويله لـ APK باستخدام PWA Builder (الأسهل)

1. ادخل على الموقع ده:
   **https://www.pwabuilder.com/**

2. في خانة **"Enter the URL of your PWA"** حط رابط GitHub Pages اللي أخذته من المرحلة 3

3. اضغط **Start**

4. استنى شوية لحد ما الموقع يفحص التطبيق

5. اضغط على زر **Package For Stores**

6. اختار **Android**

7. هتظهر لك خيارات:
   - Package ID: اكتب مثلاً `com.mina.mothakrati`
   - App name: `مذكرتي`
   - اترك الباقي زي ما هو أو عدل لو حابب

8. اضغط **Generate** أو **Download**

9. هيتحمل ملف ZIP فيه الـ APK

10. فك الضغط عن الملف، هتلاقي ملف `.apk`

---

### المرحلة 5: تثبيت الـ APK على جوالك

1. انقل ملف الـ APK لجوالك (بالبلوتوث أو واتساب أو كابل)
2. على الجوال: Settings → Security → فعّل **Install unknown apps** أو **مصادر غير معروفة**
3. افتح ملف الـ APK واضغط تثبيت
4. خلاص! التطبيق اتثبت باسم **مذكرتي**
